# Sistema de Monitoramento de Reservatório de Água 💧

Simulador simples de níveis de água desenvolvido em Python para execução no terminal. O projeto utiliza alertas coloridos para destacar os diferentes níveis de água.

## 🚀 Tecnologias Utilizadas

  Python
  Colorama (para estilização e cores no terminal)

---

## 📋 Níveis de Alerta

O sistema monitora cinco estados diferentes de risco no reservatório:
  Nível 1: Muito baixo (crítico) - 🔴 Vermelho
  Nível 2: Baixo - 🟡 Amarelo
  Nível 3: Médio - 🟢 Verde
  Nível 4: Alto - 🔵 Ciano
  Nível 5: Muito alto (alerta) - 🔵 Azul

---

## 💻 Como Executar

1. Certifique-se de ter o **Python** instalado em sua máquina.
2. Instale a biblioteca **Colorama** executando o seguinte comando no terminal:
   pip install colorama
